## ✨ 简介

Dark Lattice 是面向研究者与开发者的极客风格博客，基于 **Nightfield（夜场）** 主题构建：克制、专业、未来感，并以 3D 沉浸式交互营造深邃的阅读体验。

| | 特性 |
| :---: | :--- |
| 📚 | 学术级渲染：KaTeX 数学公式与 BibTeX 引用 |
| 🌌 | 深邃配色与 3D 空间感列表交互 |
| 📱 | 响应式布局，桌面与移动端均可沉浸阅读 |
