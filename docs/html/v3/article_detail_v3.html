抛弃卡片：流光边框与网格暴露

@ SYS_ADMIN # 2026.05.12 / READ TIME: 08 MIN

在现代 Web 开发的历程中，SaaS 的暗色模式往往走向了一个平庸的极端：无尽的、轻微带点灰度的圆角卡片流。虽然这种设计安全且干净，但它失去了“数字媒介”独有的张力。

破除“干净”的迷信

传统的 GII (Gestalt 知觉完形指数) 鼓励我们使用接近性进行隐性分组，这在多数情况下是完美的。但在构建极客风格、网络安全、或 Web3 产品时，我们需要一种更具攻击性和科技感的美学。

真正的赛博朋克设计并不是堆砌繁复的杂点，而是暴露底层的秩序。我们将 1px 的网格线直接渲染在底层，让代码的“骨骼”显形。

我们引入了 --grid-line 变量，通过双向的 linear-gradient 在 body 层面绘制无限延伸的网格。这立刻赋予了页面深度。

Conic-Gradient 的魔法

为了取代静态的卡片边界，我们利用了 CSS @property 配合 conic-gradient。这种技术的 COE (渲染优化率) 非常高，因为它完全由 GPU 处理，且不触发 DOM 重排。

这不仅仅是视觉糖果，更是状态指示器。当用户聚焦 :hover 或是系统处于计算状态时，边框的旋转速度可以由 4s 提升至 1s，形成强烈的交互共鸣。
