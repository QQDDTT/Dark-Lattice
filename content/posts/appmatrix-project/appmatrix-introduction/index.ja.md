# AppMatrix：モバイル APP バッチ生産インフラストラクチャ

モバイルインターネットが深化する今日において、単一のモバイルアプリケーションを維持することだけでも非常に困難です。さらに、複数の iOS および Android アプリケーションを同時に維持および反復開発することは、コンパイル環境、証明書の署名、および審査プロセスに関する悪夢です。

これを解決するために、私たちは **AppMatrix** プロジェクトを正式に立ち上げました。これは、モバイルアプリケーションの迅速なバッチ生産と保守のための管理プラットフォームです。

## 1. コア理念：Expo EAS を 100% 受け入れる

従来の React Native 開発では、Xcode や Android Studio の沼にはまることが避けられませんでした。macOS のアップグレード、CocoaPods 依存関係の変更、または Ruby バージョンの競合が発生するたびに、アプリを「実行」すること自体が魔術のようになってしまいます。

AppMatrix の打開策は、**Expo EAS (Expo Application Services) エコシステムを 100% 受け入れる**ことにあります：
- **クラウドコンパイル**：脆弱なローカルのネイティブコンパイル環境の依存関係をすべて排除します。コードベースには重い `ios/` および `android/` ディレクトリを保持しません。
- **証明書ホスティング**：すべての Apple 開発者証明書、Provisioning Profiles、および Google Play の Keystores は、EAS クラウドアーモリーに委任され、証明書期限切れの煩わしさから解放されます。
- **自動公開とホットアップデート**：EAS Submit と EAS Update を活用することで、クラウドビルドからアプリストアへの提出、さらには緊急の OTA ホットフィックスに至るまで、シームレスな統合を実現します。

## 2. Loop Engineering: エージェント主導の自己修復型自動化パイプライン

インフラストラクチャのクラウド化を超えて、AppMatrix は **Loop Engineering** アーキテクチャを全面的にアップグレードし、従来のエージェント支援メカニズムを**無人の自己修復型フィードバックループ**へと進化させました。

プラットフォームの基盤となる `.agents/` ディレクトリでは、ワークフローがリファクタリングされ、厳格で連続的な自動化サイクルが実現されています：
1. **自動アセンブリと脱水プロジェクト**：アプリケーションはリポジトリ内で軽量な「脱水」状態を維持します。エージェントは完全なビルドコンテキストを動的に組み立て、プレフライト段階で環境の完全性を強制的に検証します。
2. **マルチレイヤーコード検証ループ**：コード生成とコンパイルの段階で、継続的な [コード -> コンパイル/テスト -> フィードバック -> 修正] TDD ループを導入しました。静的解析とクラウドベースの E2E 自動修復を組み合わせることで、エラー発生時にエージェントがテストに完全に合格するまで自己修復ロジックをトリガーします。
3. **クローズドループの監視とホットフィックス**：オンラインのリアルタイムクラッシュ監視と統合されており、例外（カナリアテストの失敗など）をキャプチャした際に、エージェントが自動的にホットフィックスを生成し、EAS を介して緊急の OTA アップデートを実施することで、人手による介入を最小限に抑えます。

## 3. 現在のエコシステムの概要

現在、AppMatrix は2つのコアプロダクトプロトタイプをインキュベートしています：
- **MobileFileEditor**：モバイルデバイス向けに設計された軽量なファイルおよびコードエディタの探求。
- **ReceiptTracker**：クロスプラットフォームエコシステムに依存する、インテリジェントな請求書追跡および領収書管理アプリ。

各アプリケーションの背後には、`investigation/`（初期の要件分析）から `docs/`（技術アーキテクチャ設計ドキュメント）に至るまで、完全な工業化パイプラインのサポートが備わっています。

AppMatrix は、**モバイルアプリケーションの工業化と AI 支援生産**に向けた確かな一歩を示しています。
