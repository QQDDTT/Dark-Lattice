# AiSpect エンジンエコシステムと周辺マトリックス (Engines & Ecosystem)

ビジネス開発者が使い慣れたフレームワークで「侵入ゼロ」または「最小限の構成」で AI プロキシ機能を有効にできるように、AiSpect はコア基盤の外部に豊富なエンジンアダプター (Engines) と周辺エコシステムモジュールを構築しました。

## 1. エンジン適応レイヤー (Engines)

エンジン適応レイヤーの主な目標は、さまざまなランタイムホスト環境との深い統合です。開発者は対応するエンジンモジュールをインポートするだけで、必要なすべてのコアパッケージが自動的に推移的にプルされます。

### 1.1 `aispect-engine-spring`
Spring Boot 環境向けにカスタマイズされた自動構成モジュール。
- **自動構成**: `@ConfigurationProperties` を使用して `application.yml` からパラメーターを自動的に読み取り、`AiAgentBeanPostProcessor` を使用して Bean の初期化後にプロキシインスタンスの置換を自動的にスキャンして生成します。
- **依存性注入**: Agent インターフェース実装クラス自体が Spring Bean です。内部で `@Autowired` を自由に使用して、データベース Mapper、Redis クライアントなどを注入し、AI レイヤーとビジネスレイヤーの高度な統合を実現できます。
- **グラフワークフローゲートウェイ**: `AiGraphAgentSpringLauncher` を内蔵。Spring コンテナの起動後、`@AiGraphAgent` を持つ Bean をリソースプールに積極的に収集し、WebFlux などの関数型ルーティングを使用して HTTP API エンドポイント (例: `POST /ai/graph/{agentName}`) を動的に公開します。外部システムはリクエストを送信するだけで、複雑なグラフアルゴリズムの実行チェーンをトリガーできます。

### 1.2 `aispect-engine-se` と `aispect-engine-quarkus`
- **`aispect-engine-se`**: 純粋な Java SE 環境向け。ミニマリストの静的ファクトリまたはビルダー API を提供します。開発者はオブジェクトのライフサイクルを手動で管理し、`AiClient` を組み立てるため、基本的なサーバーサイドまたはコンソールアプリケーションに適しています。
- **`aispect-engine-quarkus` (計画中)**: クラウドネイティブな Quarkus フレームワークを対象としており、GraalVM AOT のビルド時拡張機能に焦点を当てています。コンパイルフェーズで Quarkus Extension を通じてプロキシクラスのバイトコードを生成し、超高速な起動と極めて低いメモリフットプリントという設計理念に合致しています。

## 2. 組み込み Agent インスタンスセット (`aispect-agents`)

コアコントラクトの抽象化が API レイヤーに下降するにつれて、このモジュールは特定のモデルベンダーに依存しない、**すぐに使える豊富な組み込み Agent 実装ライブラリの提供**へと移行します。
- **データ処理カテゴリ**: テキストクリーニング (`DataCleanAgent`) や強制的な構造化 JSON 抽出 (`JsonExtractorAgent`) など。
- **フロー制御カテゴリ**: 条件付きルーティング分岐 (`ConditionalRouterAgent`) やタイムアウト/例外フォールバック戦略 (`FallbackAgent`)。
- **審査およびリスク制御カテゴリ**: コンテンツコンプライアンスチェック (`ContentModerationAgent`)。
- **グラフルーティングの例**: ストリーミング (SSE) 出力とコンテキストグラフルーティングの処理方法を示す `StorytellingGraphAgent` など。

## 3. 補助プロジェクトマトリックス

### 3.1 ベストプラクティスの例 (`examples`)
直感的で、すぐに使える体験を提供します。
- **`example-java-se`**: CLI 自動化ファイルアシスタント。ツールの呼び出しとローカルファイルとの対話を紹介します。
- **`example-spring-boot`**: AI ドキュメントインテリジェント編集 Web プラットフォーム。Agent がフロントエンドのシングルページアプリケーションやバックエンドの Service 依存性注入とどのように統合されるかを示します。
- **`example-quarkus`**: Webhook を介したリアルタイムのコード欠陥分析を示します。

### 3.2 専用テストスキャフォールド (`aispect-test`)
ビジネス側に提供されるオフラインテストツールライブラリ。
- **`MockAiClient`**: 実際の API を必要とせずに、固定された戻り値、ネットワークタイムアウト、またはコンテンツ審査のブロックをシミュレートします。
- **コンテキストの偽造**: `InvocationContextBuilder` を介してプロキシ実行スナップショットを迅速に組み立てます。
- **Spring Test Slices**: データベース接続などの重いコンポーネントを起動せずに、ローカライズされた Agent インターセプトチェーンをすばやく立ち上げるためのテストスライスサポートを提供します。

### 3.3 バージョン管理とファサード (`bom` と `website`)
- **`aispect-bom`**: Maven を介して内部および外部の依存関係バージョンを一元管理するため、外部統合では単一の POM をインポートするだけで済みます。
- **`aispect-website`**: VitePress で構築されたパブリックポータル。パブリック API、JavaDoc、および統合ガイドのみが含まれています。コアビジネスロジックのプライバシーを確​​保しながら、プロフェッショナルなオープンソース製品のイメージを確立します。
