# 大規模モデルの能力と制限の分析 (Project AURA 拡張)

このガイドは、Google AI Studio ダッシュボードのクォータデータ (Project AURA 向け) に基づいています。リアルタイムの使用量は削除され、レート制限のみが保持され、さまざまなモデルやツールのコアな使用方法が要約されています。AiSpect のマルチエージェントオーケストレーションでは、異なる特性と制限を持つこれらのモデルを合理的に活用することが、コストと応答速度を最適化する鍵となります。

## 1. コアモデルマトリックス (Models)

さまざまな Agent のスケジューリングニーズを満たすために、プラットフォームは的を絞って最適化された一連のモデルを提供します。

### 1.1 テキストと推論の主力 (Text Generation)
- **超高速軽量モデル (Flash Lite シリーズ)**: `Gemini 2.5 Flash Lite` や `Gemini 3.1 Flash Lite` など。非常に高い 1 日あたりのリクエスト制限 (RPD 最大 500) を持ち、超低遅延の要件に最適化されており、高同時並行、大量の基本的なテキスト処理、パイプラインタスクに非常に適しています。
- **費用対効果の高い基盤モデル (Flash シリーズ)**: `Gemini 3.5 Flash` や `Gemini 2.5 Flash` など。通常のテキスト生成、軽量な Agent 開発、高頻度の API ポーリングに適しています。
- **複雑な推論モデル (Pro シリーズ)**: `Gemini 2.5 Pro` や `Gemini 3.1 Pro` など。複雑な論理推論、深いコード生成、長文理解のために特別に設計されています。厳密な学術的または技術的な推論を必要とするシナリオに適しています。

### 1.2 高度な Agent 抽象化 (Agent Models)
- **自律プログラミング (Antigravity)**: 独立した Linux サンドボックスと組み込みブラウザを備え、自発的に計画、作成、実行し、自律的にコードをデバッグおよび修復できます。
- **自律調査 (Deep Research Pro)**: 複雑なトピックに関するマルチステップのウェブ検索、文献の閲覧、および詳細なレポートの生成を自発的に実行できます。
- **コンピューター操作 (Computer Use)**: スクリーンショット、シミュレートされたマウスクリック、キーボード入力などを通じて、オペレーティングシステム (OS) を直接操作できます。

### 1.3 マルチモーダルおよび周辺エコシステム (Multimodal & Others)
- **音声マルチモーダル (TTS & Native Audio)**: 高度に自然なストリーミング音声合成をネイティブにサポートし、ミリ秒の遅延を持つ双方向のリアルタイム双方向 API (`Live API`) もサポートしており、リアルタイム音声アシスタントの開発に適しています。
- **画像/ビデオ/音声の作成**: 最先端の画像生成 (`Imagen 4`)、ビデオ生成 (`Veo 3`)、音楽/音声作成 (`Lyria 3`) が含まれます。
- **全モーダル融合 (`Gemini Omni Flash`)**: テキスト、オーディオ、ビデオをネイティブに同期的に処理し、真のクロスモーダルな入出力を実現します。
- **基盤の拡張機能**: ベクトル埋め込み (`Gemini Embedding`)、ロボットの具体化制御 (`Gemini Robotics ER`)、オープンソースの軽量展開 (`Gemma 4`) など。

## 2. ツールとグラウンディング機能 (Tools & Grounding)

グラウンディング (Grounding) ツールを使用すると、大規模モデルは回答を生成する際にリアルタイムの外部の信頼できるデータソースにアクセスできるようになり、「ハルシネーション」の現象を大幅に減らし、情報の適時性を確保できます。

- **検索グラウンディング (Search Grounding)**: Gemini 2 / 2.5 / 3 シリーズをサポートします。有効にすると、モデルは回答する前に Google 検索を自動的に呼び出して最新のリアルタイムウェブページ、ニュース、または技術ドキュメントを取得し、回答に引用リンクを含めます。
- **マップグラウンディング (Map Grounding)**: Deep Research および一部の Gemini 基盤モデルをサポートします。有効にすると、モデルはリアルタイムで Google マップデータベースにクエリを実行して、正確な地理的位置、販売者情報、ルート計画、および空間 POI データを取得できます。

異なるティアのモデルとグラウンディングツールを合理的に組み合わせることは、複雑なビジネスフローにおいて AiSpect Graph Agent を効率的かつ安定して稼働させるための基盤となります。
