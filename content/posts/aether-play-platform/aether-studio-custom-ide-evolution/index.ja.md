# 汎用 VSCode からの脱却：専用ゲーム開発環境 Aether Studio の誕生と進化

クラウドベースのオンライン開発環境を構築する際、多くのチームは VSCode のオープンソース版である `code-server` をデフォルトの選択肢として検討します。充実した拡張機能と慣れ親しんだ UI は、一見すると「Web 上でのコーディング体験」を迅速に実現してくれるように思えます。

しかし、**Aether-Play** が対面パーティゲームの多人数共同開発と低コストなクラウド運用へ進出するにつれ、汎用 code-server の構造的な課題が顕在化しました。ハードウェア効率の極限追求と独自の二画面テスト体験を実現するため、チームは汎用 VSCode を廃止し、専用の超軽量 Web IDE **Aether Studio** をゼロから開発しました。

---

## 1. 汎用 code-server を廃止した4つの理由

```
               ┌──────────────────────────────────────────────┐
               │         汎用 code-server の致命的課題        │
               └──────────────────────┬───────────────────────┘
                                      │
         ┌───────────────────┬────────┴──────────┬───────────────────┐
         ▼                   ▼                   ▼                   ▼
    【メモリの浪費】       【イメージ肥大化】     【モバイル対応の破綻】  【パーティゲームとの乖離】
  アイドル時 1.5GB 消費    コンテナ 2GB 超        ソフトキーボードで破版  二画面同時テストが不可能
```

1. **耐え難いメモリ消費 (RAM Bloat)**：コードを開いていないアイドル状態でも、code-server コンテナは **1.2GB〜1.5GB** ものメモリを常駐消費します。低コストな GCP Spot インスタンス（`e2-medium`、メモリ4GB）上では、プラットフォームと併用するだけで OOM（メモリ枯渇）によるプロセス停止が頻発しました。
2. **コンテナイメージの肥大化**：ベースイメージが **2GB** を超え、インスタンス起動時のイメージプルに数分を要し、機動的なデプロイを妨げていました。
3. **モバイル・タッチ操作への不適応**：デスクトップのマウス・キーボードに最適化されているため、iPad やスマートフォンから簡易修正を行おうとすると画面が崩れ、操作性が著しく低下しました。
4. **二画面ゲーム設計との断絶**：大画面と個人スマホが連動するゲーム体験を VSCode 内で再現できず、ブラウザの複数タブを手動で行き来する非効率なテストを強いられていました。

---

## 2. Aether Studio が達成した軽量化とイノベーション

Aether Studio は汎用 IDE の重厚なレガシーを捨て去り、軽量 HTML5 パーティゲーム専用に最適化されました：

- **メモリ消費を 95% 削減**：軽量な Node.js バックエンドとモダンなフロントエンド実装により、ワークスペースごとのメモリ常駐を 1.5GB から **50MB 未満** へ激減；
- **起動時間ゼロの即時性**：プラットフォーム本体に直接組み込まれ、秒単位でのワークスペース起動を実現；
- **サイバーアーケード・ワークショップ視覚言語**：すりガラス効果（Backdrop-Filter）、ネオンアクセント、低遅延アニメーションにより、没入感あふれる開発環境を提供。

## 3. 専用「4-in-1 ワークベンチ」構成

Aether Studio は複雑な汎用設定を排除し、ゲーム開発に必要な4つのコア領域に集約しています：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              Aether Studio 4-in-1 ワークベンチ                         │
├──────────────┬───────────────────────────────┬─────────────────────────────────────────┤
│ 1. アセット  │ 2. デュアルモードエディタ     │ 3. ツインデバイスエミュレータ           │
│    ドロワー  │ - CodeMirror 6 コード編集     ├────────────────────┬────────────────────┤
│ - ソース     │ - シナリオ連線ビジュアル編集  │ 共有大画面 (TV)    │ 個人スマホ (Phone) │
│ - 設定       │                               │ - 全体イベント放送 │ - タッチ・覗き見防 │
│ - 共有素材   │                               ├────────────────────┴────────────────────┤
│              │                               │ 4. postMessage 実行時イベント解析器     │
└──────────────┴───────────────────────────────┴─────────────────────────────────────────┘
```

### 3.1 資産ドロワー (Asset Drawer)
- 権限のあるゲームファイル（`game.json`、`index.html`、`script.js`、`style.css`）のみを整然と表示；
- 共通効果音やベクター小道具、規約ドキュメントを読み取り専用で安全にマウント。

### 3.2 デュアルモードエディタ (Dual-Mode Editor)
- **コードモード**：**CodeMirror 6** を採用し、シンタックスハイライト、括弧補完、自動インデントを低遅延で提供；
- **キャンペーン連線モード**：`kind: campaign` のシナリオ戦役に対し、ドラッグ＆ドロップでストーリー分岐とミニゲーム挑戦を可視化・配線できるノードグラフを提供。

### 3.3 ツインデバイスエミュレータ (Twin Device Simulators)
Aether Studio 最も画期的な機能：
- 画面右側に2つの画面を並列配置：**左に共有大画面（16:9 横向き）、右にスマホ画面（9:19.5 縦向き）**；
- 内部の仮想 WebSocket で両画面が常時連動。スマホ側でボタンを押すと、即座に大画面の盤面が更新されるため、実機端末を何台も並べてテストする煩わしさが完全に解消されました。

### 3.4 実行時 postMessage イベント解析器 (Event Inspector)
ゲーム Iframe とホスト間の双方向通信をリアルタイムに監視：
- `AETHER_GAME_READY`、`MG_INIT`、`MG_PROGRESS` などの規約イベントを構造化表示；
- ワンクリックで手動モックイベント（HP 減少やバイブレーション発生など）を注入し、境界条件のテストを即時に実行。
