# AuraからEvo-StudioとSyntax-Labへ：AI主舞台の自律型IDE工房と純フロントエンド・タイムトラベル実験室への世代的飛躍

> **進化の主軸**：初期の `Aura` リアクターシステムおよび `CSharp/JavaTeachingSolution` の退役 $\to$ **`Evo-Studio`（主控）** と **`Syntax-Lab`（プラットフォーム）** への全面移行  
> **連携マトリックス**：`Nex-Micro`（IoT Web Serialクラウドビルド）、`Nomos-Core`（法務・税務ガバナンス智庫）、`Quant-FMP`、`Quant-FX` v4.0、`Nexus-Mini` 等12大コアプラットフォームの同時進化

---

## 1. 主控層の世代的飛躍：なぜ `Evo-Studio` は `Aura` を完全に代替したのか？

初期の探求において、`Aura` はRustベースの独立したAIエージェント・リアクターOSの構築を目指していました。しかし、マルチエージェント開発の実践が深まるにつれ、**人間とAI艦隊が協働する真の主戦場は、開発フローから切り離されたバックグラウンドデーモンではなく、次世代の自律型IDEおよび計算力ルーティング工房そのものの再発明にある**ことが明確になりました。

そのため、`Aura` リポジトリと関連ドメインを正式に退役・削除し、主控層の **`Evo-Studio`（演化工房）** へと全機能を統合・昇華させました：

1. **従来型IDEの画面比重を逆転（AIが絶対的主舞台へ）**：
   従来のIDEは画面の80%をテキストエディタが占め、AIは狭いサイドバーに押し込められていました。`Evo-Studio` はこの比重を完全に逆転させ、**マルチエージェント作戦ボード、タスク分解DAG（有向非巡回グラフ）、自動検証パイプライン、クラウド・ローカル計算力モニター**をメインステージの中央に据え、コードDiffやターミナル、プレビューサーバ、マルチモーダル資産をオンデマンドのサブモジュールとして統合しました。
2. **エッジ・クラウド2層認知ルーティング（Tiered Cognitive Routing）**：
   意図分類、ファイル検索、定型スクリプト生成、DAG分解はローカルの14B量子化モデル（Ollama・限界コスト `$0.00`）で即時処理し、高度なアーキテクチャ推論やレッドチーム監査のみをクラウドの最上位モデルへルーティングします。
3. **ハードウェアとローカルDockerサンドボックスの融合**：
   Framework Laptop 13（2TB NVMe）とローカルDockerコンテナビルドを組み合わせ、ホスト環境を一切汚染することなくミリ秒単位のビルドを実現します。

## 2. プログラミング機構教育の再発明：`TeachingSolution` から `Syntax-Lab` へ

初期の `CSharpTeachingSolution` と `JavaTeachingSolution` はローカルの `.sln` やMavenプロジェクトに依存しており、「ホストゼロランタイム」の原則と矛盾するだけでなく、コンソールへの黒箱的なテキスト出力しか行えませんでした。

この2つの初期プロジェクトを完全に廃止し、新たにコアプラットフォーム **`Syntax-Lab`（構文とアーキテクチャ実験室、`https://syntax.evotensor.dev`）** を創設しました：

| 比較軸 | 初期の `CSharp / Java TeachingSolution` | 新設 **`Syntax-Lab` (`syntax.evotensor.dev`)** |
| :--- | :--- | :--- |
| **実行環境依存** | ローカルへの .NET SDK / Java JDK 導入が必須 | **100% 純フロントエンド・ゼロ依存**（ブラウザのみで即座に対話演習） |
| **対象言語** | C# と Java が別々のリポジトリに分断 | **C# / Java / Rust / Go / TS の5言語を同一画面で横断比較** |
| **可視化手法** | 静的コード閲覧＋コンソール文字列出力 | **タイムトラベル・ステッパー＋スタック／ヒープメモリSVG動的キャンバス** |
| **端末適応** | デスクトップIDEのみ | **PC `100dvh` 3ペイン実験台＋モバイル横スクロールゼロのカード閲覧流** |

`Syntax-Lab` は**4大コア実験ポッド（Pods）**で構成されています：
- **Pod 01・言語内部機構＆メモリモデル横断比較**：スタック対ヒープ割り当て、ボクシング、`vtable` 対 Rust `dyn Trait`、リフレクション、世代別GC対Rust所有権ライフタイム、`async/await` 状態機械対Go `G-M-P` スケジューラ；
- **Pod 02・アルゴリズム＆並行データ構造ステップ実行**：AVL木・赤黒木・B+木の回転と分割、`HashMap` の赤黒木化、CASロックフリーRingBuffer、動的計画法の逆方向・順方向ステップ再生；
- **Pod 03・GoF 23デザインパターン実戦解体**：ゲートウェイ責任連鎖やクオンツ注文状態機械など実務シナリオに基づくUMLコールチェーンの動的推演；
- **Pod 04・分散＆高並行システムアーキテクチャシミュレータ**：QPSや障害率スライダーを操作し、トークンバケット制限、サーキットブレーカーの3状態遷移、キャッシュスタンプード防御をリアルタイム再現。

## 3. 12大コアプラットフォーム群の最新ブレークスルー

- **`Nex-Micro` (`micro.evotensor.dev`)**：ESP32/ESP8266向けクラウドファームウェアビルドとブラウザ **Web Serial API** ゼロインストール書き込み・IoTテレメトリ基盤を統合；
- **`Nomos-Core` (`nomos.evotensor.dev`)**：スタートアップからスケール期までの法務・税務・SLA契約ガバナンス智庫と対話型エクイティ希薄化・研究開発税制シミュレータ；
- **`Quant-FMP` & `Quant-FX` v4.0**：`Quant-FMP` は15年データレイク同期（+6,049深層バー）とMomus監査13項目の完全改修（品質ゲート99.9/100）を達成；`Quant-FX` はv4.0日中短期戦略への刷新と3ラウンドの対抗監査を完了；
- **`Nexus-Mini` & `Chrono-Lens`**：`Nexus-Mini` はゼロリモート通信3層アーキテクチャと `STYLE-57 × STYLE-39` SVG造形を確立；`Chrono-Lens` は5大理念フィールド遷移アニメーションと $44\times 44\text{px}$ タッチターゲット強化を完了；
- **`Aegis-Gate` & `SynapseGate`**：コアプラットフォーム層へ統合され、ゼロ攻撃面暗号ゲートウェイおよびAI無感注入プロキシとして稼働。
